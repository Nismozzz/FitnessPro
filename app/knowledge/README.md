# 文献库资料规范

## 来源筛选

优先系统综述、荟萃分析和权威指南；不将营销文章、无出处科普或单项小样本研究作为默认理论依据。整理者应核对原文的研究人群、干预条件、比较组、效应量、置信区间、异质性、偏倚风险及敏感性分析。不能将统计不显著写成证明等效，不能将分组界限写成确定的生理阈值，不能把群体平均结果直接变成个体处方。

当前五篇资料均为用户整理的摘要，不是论文全文。DOI 与标题已通过 Crossref 匹配，结论尚未逐项对照原文核验。`data/knowledge/sources.json` 保留每篇待核对说明，尤其 TRE 摘录中核心摘要和亚组数值的表述冲突。冲突须由整理者回原文人工甄别；系统不会自动裁定，入库不代表消除了冲突。

## 新增与更新

原始 Markdown 放到 `data/knowledge/raw/`，保留 YAML 头：

```yaml
---
title: 论文标题
authors: 作者、年份与刊物
source_url: https://doi.org/真实DOI
category: 容量管理
review_note: 摘录未核对全文；待核对的具体限制或冲突
---
```

已有资料缺少链接时，可在相邻 `sources.json` 以文件名为键补充，避免修改原始摘录。标题、作者和 HTTPS 来源链接为必填字段；无法确定出处时应先核对，不编造链接。

按标题分节、按段落/换行/句号/分号/空格递归分割，默认每块不超过 900 字符；不调用 LLM 改写摘要。每块保留标题、作者、来源链接、源文件名、节标题、原文、待核对说明；ID 由文件名、章节和内容生成，重复入库稳定，内容更新会改变片段 ID。

运行 `python -m scripts.ingest_knowledge` 重建独立文献索引，重启后端加载新版本。可用 `--skip-embed` 离线构建仅 BM25 的版本；该选项会清除旧向量文件，防止新文档误用旧向量。构建失败保留旧索引；目录切换时保留回滚备份。模型或内容哈希、ID 不匹配时禁用向量检索并显示降级提示，不静默使用旧向量。

## 检索、引用与评测

`search_knowledge_articles` 只读检索；复用 BM25、Qdrant（可配置本地向量库）、Embedding、RRF 与 Reranker，不混入动作库。返回候选不等于已证明支持用户问题；证据不足时回答须明确说明，联网只补足缺失内容。

引用按完整片段纳入预算，超出预算整块省略，不截断证据 JSON。前端可点击文献引用查看作者、链接、章节、原文与待核对说明；历史引用使用回答时的快照。文献工具结果复用现有 RAGAS 旁路评分，但 RAGAS 忠实度只判断回答与摘录是否一致，不负责验证摘录是否准确反映论文全文。

`eval/knowledge/cases.json` 是 10 条正例、2 条无答案问题的种子集，标签尚未独立复审。按文献去重评估 Recall/MRR@3 与无答案识别率；不能把这个小集的结果当成广泛问题上的真实准确率。混合检索评测必须具有可用向量索引；降级信息保存在每条结果中。
